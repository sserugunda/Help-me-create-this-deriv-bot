Run the backtester

1) Install dependencies:

   pip install -r requirements.txt

2) Start the app:

   streamlit run streamlit_app.py

3) Upload three CSVs when prompted:

- ticks: columns `timestamp`, `price`
- 1-minute candles: columns `timestamp`, `open`, `high`, `low`, `close`
- 2-minute candles: columns `timestamp`, `open`, `high`, `low`, `close`

Timestamps can be ISO-8601 or epoch seconds/milliseconds.
